# SlimsteMens.Maui

Een eenvoudige .NET MAUI demo gebaseerd op het tv-programma *De Slimste Mens*.

## Benodigdheden
- .NET 9 SDK
- MAUI workload (`dotnet workload install maui`)

## Bouwen
```
dotnet build
```

## Starten
Open de solution in Rider en start het `SlimsteMens.Maui` project voor Windows.
