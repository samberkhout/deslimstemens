# Slimste Mens WPF

Deze repository bevat een voorbeeld van een WPF applicatie in de stijl van *De Slimste Mens*.

## Bouwen

```
dotnet build
```

## Starten

```
dotnet run --project SlimsteMens.Wpf
```

De PresenterWindow opent op het primaire scherm. Een tweede AudienceWindow wordt fullscreen op het tweede scherm geplaatst.
